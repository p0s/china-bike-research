# Third-party material

Product names, brand names, trademarks, linked webpages, and third-party product photography belong to their respective owners. Inclusion does not imply endorsement, partnership, sponsorship, or authorization.

## Product images

Each published visual has a structured record in `data/images/` with:

- the exact platform and, when applicable, configuration it depicts;
- an exactness label;
- the original source page;
- the image owner or credited party;
- a rights/hosting status;
- alt text and a review date.

The repository includes only original project placeholder SVGs. Records marked `official-page-embed` or `retailer-page-embed` point the visitor’s browser to a third-party-hosted image; the third-party image file is not committed to this repository and is not licensed under the repository’s MIT or CC BY licenses.

A remote image URL must not be copied into the repository as a local file unless the rights holder grants permission or the file has a compatible license. Forks and downstream users remain responsible for their own use of third-party images.

Remote hosts can change, block, or remove an image. The site therefore labels image exactness, provides a local fallback, and publishes an image-policy page. Rights concerns can be resolved by removing the remote reference and retaining the original project placeholder.

## Source text

Source URLs and short original summaries are provided for research and verification. Do not copy long passages, social-media posts, marketplace screenshots, or reviewer material into the repository without permission or a compatible license.
