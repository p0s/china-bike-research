# Published schemas

These JSON Schema files describe the main public JSON record types for editors and external tools, including product-image, curated-video, atomic research-attempt, and immutable Taobao manual-capture packet records. The executable validators add cross-reference, uniqueness, date, range, local-file, image-rights, video-target, source, price-history, search-exhaustion, packet path, byte/hash, collision, and privacy checks that JSON Schema alone does not cover.
